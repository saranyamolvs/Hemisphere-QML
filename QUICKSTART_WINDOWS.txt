ANACONDA + JUPYTER NOTEBOOK

1. Extract the complete project to a local folder. Keep Schlieren_POD_QSVM.ipynb
   together with the schlieren_qml and configs folders.

2. Open Anaconda Navigator and launch Jupyter Notebook. Browse to the project
   folder and open Schlieren_POD_QSVM.ipynb.

3. Select your Python kernel and run cells from the top using Shift+Enter.
   The setup cells show the Python executable and check required packages.
   If needed, run the notebook's %pip installation cell, restart the kernel,
   and run again from the beginning. Python 3.10 or newer is required.

4. Set IMAGE_DIRECTORY to your TIFF folder, e.g.
   IMAGE_DIRECTORY = r"D:\Schlieren\Mach2_run01"
   Start with ROI = None. Inspect the full-frame preview, then enter a crop as
   ROI = [x0, y0, x1, y1] in original pixels and rerun the preview.

5. Keep the initial limit at 200 and stride at 1. Run the pilot cell, then the
   figure and table inspection cells. The run prints the saved output folder.
   Keep outputs separate from the folder of raw TIFF images.

6. Review the pilot before enabling the full-record section. RUN_FULL is False
   by default. See docs\ANACONDA_JUPYTER.md and README.md for disk requirements,
   binning, optional Conda setup and troubleshooting.

No separate venv is needed when using your Anaconda notebook environment.

ALTERNATIVE: POWERSHELL COMMANDS

1. Open PowerShell in the extracted project folder.

2. Run once:
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt

3. Open configs\pilot.json in a text editor. Change image_directory to your
   folder, e.g. D:/Schlieren/Mach2_run01. Keep limit=200 and stride=1.

4. Optional crop:
   .\.venv\Scripts\python.exe -m schlieren_qml select-roi "D:/Schlieren/Mach2_run01/frame00001.tif"
   Drag a rectangle, press Enter, copy the printed roi into configs\pilot.json.

5. Run:
   .\.venv\Scripts\python.exe -m schlieren_qml run configs/pilot.json

6. Inspect results\pilot\figures and the JSON/CSV output tables.
   Start with mean/RMS, modes, variance spectrum and state-conditional means.

7. After reviewing the pilot, edit configs\full.json and run the same command
   with configs/full.json. Read README.md for disk requirements and binning.

No experimental frames/results are bundled. No labels are currently available:
the candidate states are statistical clusters, not established physical regimes.
The quantum fidelity kernel uses an exact classical simulator. See README.md and
docs\PAPER_GUIDE.md before interpreting classification scores for a paper.
